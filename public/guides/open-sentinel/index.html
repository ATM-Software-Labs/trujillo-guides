Telemetría Host y Alertas Forenses de Intrusión (Open-Sentinel)

Alberto Trujillo Mingorance · @atrumin16 · Guides

Arquitectura completa para monitorizar el ciclo de vida de arranque de endpoints, recolectar telemetría diferencial de hardware y despachar alertas criptográficamente firmadas a Discord, Telegram y WhatsApp sin servidores intermedios.

1

Fase 1: Daemon de Arranque y Telemetría Diferencial

El servicio de Open-Sentinel se engancha al arranque del kernel mediante systemd (Linux) o el Programador de Tareas (Windows). Captura el diferencial de red, dirección IP pública Anycast, MAC address de interfaces físicas y métricas térmicas en sub-500ms.

# Captura instantánea de telemetría diferencial python main.py --daemon --silent --audit-integrity
Parámetro Métrica Recolectada Objetivo Forense
Red IP Pública + BGP ASN Detectar si el host se ha iniciado fuera de la red local autorizada.
Hardware CPU Load / RAM / GPU Thermals Garantizar salud térmica e identificar minería o procesos ocultos en el arranque.
Integridad SHA-256 Manifest Comprobar que ningún binario del sistema ha sido alterado offline.
2

Fase 2: Pipeline de Alerta Multicanal con Fallback

Para evitar puntos únicos de fallo (SPOF) en caso de caída de una API de mensajería, Open-Sentinel implementa un pipeline en cascada con reintentos exponenciales:

Canal Protocolo / SLA Formato de Payload
Discord Webhook HTTPS (TLS 1.3) Embed enriquecido con código de colores, uptime, geolocalización y telemetría.
Telegram Bot API Direct Endpoint Mensaje Markdown con soporte para alertas de emergencia y comandos remotos.
WhatsApp Cloud API / Twilio Gateway Fallback de alta prioridad cuando los canales primarios fallan o no hay conexión web.
3

Fase 3: Endurecimiento Zero-Trust y CI/CD

Todo el código está auditado con análisis estático de seguridad Bandit (SAST) y verificado contra fugas de entropía (Shannon Entropy) antes de cada commit. Las claves privadas y tokens nunca tocan el disco en texto plano.

# Pipeline CI de seguridad automatizado en GitHub Actions - name: Zero-Trust Security Audit run: bandit -r src/ -ll -ii
